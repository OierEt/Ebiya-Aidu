# My site

Plain HTML + CSS. No installs needed.

## See it
Double-click `index.html`. It opens in your browser.

## Edit it
- Texts: open any `.html` file in a text editor (VS Code is fine) and change the words between the tags.
- Colours and fonts: the first lines of `css/style.css`.
- Anything inside a card with the dashed border is a placeholder. Fill it in and delete `todo` from its `class="card todo"`.
- Photos: put them in a new `img/` file and replace `<div class="photo a"></div>` with `<div class="photo"><img src="img/yourphoto.jpg" alt="description"></div>`.
- To add a page: copy `notes.html`, rename it, and add a link in the `<nav>` of every page.

## Publish it (free)
1. Create a GitHub account and a repository named `YOURUSERNAME.github.io`.
2. Upload all these files (Add file > Upload files).
3. In Settings > Pages, choose the `main` branch. In a minute it is live at `https://YOURUSERNAME.github.io`.
